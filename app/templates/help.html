1. 软件概览

1.1 开发目的

本软件旨在可视化心肌细胞信号，深度解析心肌细胞放电信号所携带的具体生理信息，为实现智能化生理分析平台提供前期基础。

软件基于 Web 技术（HTML5/Flask） 开发，实现了从传统桌面应用到 B/S 架构的跨越，用户无需安装 MATLAB 即可在浏览器中运行。

1.2 技术特点

面向对象的系统架构

模块化程度高，便于功能扩展与维护，代码复用性强。

多通道信号并行处理

支持同时处理 60 个通道的心肌细胞信号，具备高效的加载与分析能力。

灵活的交互式可视化

提供原始波形、二维热力图、滤波后信号等多种展示方式。

智能信号分析

集成 R 峰检测、T 波识别算法，自动生成峰值报告。

2. 主要功能模块介绍

该平台主要有两大模式，为离线模式和实时监测模式，主要涉及五大模块，分别为输入模块，原始信号观察模块，放电行为分析模块，信号处理模块，输出模块。

系统初始页面

2.1 输入模块

功能说明：该平台离线模式支持用户导入心肌信号的 .h5 格式文件，用于分析不同的测试数据。

操作流程：点击 文件夹按钮，选择本地h5文件，等待数据平台读取数据直至显示“读取文件成功”。

输入模块界面及其操作流程

2.2 原始信号观察模块

功能说明：

  • 面板 1 (Overview)：显示 60 个通道的信号缩略图。通过调整控制界面的电压范围，时间间隔，以及起始时间来呈现用户需要的图像。
  • 面板 3 (Detail)：显示特定通道的精细原始图像。输入特定的通道，会在面板 3 上呈现该通道的原始心肌细胞信号图像，用于直观呈现数据和信息。

操作流程：

用户点击“Plot”按钮，面板 1 上可绘制 60 个通道的原始心肌细胞信号的缩略图。输入“Tab”中任意的通道标签，点击“Plot”按钮，可在面板 3 上呈现该通道的原始心肌细胞信号图像。可调节“Voltage”来控制纵轴的电压范围，调节“Time Interval”来控制横轴的时间间隔，调节“Start Time”来控制横轴的开始时间。

原始信号观察模块界面及其操作流程

2.3 放电行为分析模块 (Heated Map)

功能说明：

对 Raw Data Explorer 中的数据进行分析，得到放电此时，再针对每次放电事件， 生成放电顺序的的二维热力图，展示放电顺序随时间的变化，并且可绘制梯度场矢量。同时显示每次放电第一个电极的实际测量时间。

可视化特征

  • 颜色条：对应数值最低的颜色（如深蓝）代表起始放电位置。
  • 箭头模拟：可选择用箭头的大小和方向模拟放电传播过程。

操作流程：

用户点击“Discharge Analyse”进入放电分析界面。点击 “Discharge Detection”，算法即可检测出放电次数。 调整“Epoch”选择观察第几次放电，即可在“Time”栏中得到该次放电的开始时间。 随后点击“Plot”按钮，可在面板2 上呈现该次放电顺序随时间变化的二维热力图。在面板2中，对应数值最低的颜色条（蓝色）为此次放电的第一个电极的实际位置。 点击“Arrow”按钮为热力图加上梯度场矢量，点击“Remove”去掉箭头。

放电行为分析模块界面及其操作流程

2.4 信号处理模块 (Filtered Signal)

功能说明：从 60 个通道中选择特定通道，显示处理后的信号。

信号类型 (Type)：

All Signals
综合显示所有步骤
Original Signal
原始信号
With R-Peaks
带 R 峰标注
Cleaned Signal
去噪后的信号

点击 Analyze 按钮可输出 R 和 T 波的峰值报告。

操作流程：

切换为“Filtered Signal”界面，输入“Channel”中任意的通道标签，点击“Plot”按钮或按键盘上的“Enter”键，在坐标轴 4 上呈现该通道的处理后的细胞信号图像。 调节“Time Interval”来控制横轴的时间间隔。 调节“Start Time”来控制横轴的开始时间。 选择“Type”中的不同信号类型“All Signals”，“Original Signal”，“Original Signal with R-Peaks”，“Cleaned Signal”来显示不同处理后的细胞信号图像。 点击“Analyze”按钮，输出R和T波的峰值报告，等待数据计算，出现“ECD 节点时间已成功保存”提示，代表保存成功。

信号处理模块界面及其操作流程

2.5 输出模块

功能说明：允许用户自定义文件名，将各个坐标轴的图像保存为背景透明的格式。同时支持导出 R 和 T 波的峰值分析报告。

3. 软件使用详细说明

第一步：进入初始界面

1

打开浏览器访问网页，进入初始界面。界面包含：左侧导航栏（界面选择）、中间控制区（参数设置）和右侧绘图区。

第二步：输入文件

2

在 Raw Data Explorer 界面，点击黄色的文件夹图标。选择本地存储的 H5 文件并打开。等待系统提示“文件读取成功”。

第三步：绘制原始心肌信号图像

3
  1. 点击 Plot 按钮，在坐标轴 1 上绘制 60 通道缩略图。
  2. 在 Tab 输入框中输入通道号（如 21），再次点击 Plot，坐标轴 3 将显示该通道细节。
  3. 调节 Voltage 和 Time Interval 优化视图。
  4. 点击 Export 按钮保存图像。

第四步：绘制放电顺序热力图

4
  1. 切换至 Heated Map 界面。
  2. 输入 Discharge 次数（如 3），点击 Plot。坐标轴 2 将显示热力图。
  3. 调节 Color Picker 更改颜色风格。
  4. 点击 Arrow 按钮添加传播方向箭头。
小技巧： 将热力图显示的 Time 复制回 Raw Data Explorer 的 Start Time，可精确定位原始波形。

第五步：绘制处理后的信号图像

5
  1. 切换至 Filtered Signal 界面。
  2. 输入 Channel 通道号。
  3. 选择 Type（如 Cleaned Signal），点击 Plot。
  4. 点击 Analyze 按钮，等待数据计算。出现“ECD 节点时间已成功保存”提示即代表成功。

4. 实时在线监测 (Web版专属功能)

注意：此功能需登录账号后使用。

Web 版本支持通过 WebSocket 协议连接实验室设备，实现远程实时监控。

操作步骤

  1. 点击右上角头像 → 登录。
  2. 登录后进入 我的设备 页面。
  3. 点击 添加新设备，填写设备名称与 IP。
  4. 点击设备卡片上的 连接监测 按钮。
  5. 系统自动跳转回主界面，实时波形将覆盖静态图表。
